# signetartists.com

This repository is public: GitHub Pages serves the site from it, and anyone can
read every file and commit.

- Write no notes into content files: no `notes`, `_notes` or `_…note` fields.
  `scripts/no_notes.py` runs before every build and fails it if one appears.
- Keep reasoning, strategy, sales process and internal briefs out of code
  comments, READMEs and commit messages. Commit messages say what changed, plainly.
- Signet's private notes and process live in its own private workspace, outside
  this repository. Record decisions there.
