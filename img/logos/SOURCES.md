# Client logo provenance

The marks in the client strip (site.json `credits`, rendered by build.py
`credits()` on the home page and /corporate/). Each is the trademark of its
owner, used only to name a company the roster's artists have played for, which
is the ordinary nominative use every client strip on the web relies on. Nothing
here implies endorsement, and a takedown request from any owner is honoured by
removing the entry from site.json and deleting the file.

Every file was pulled from Wikimedia Commons or English Wikipedia on
2026-09-03 and normalised by hand-run script: XML prolog, editor metadata and
background squares stripped; every fill set to `currentColor` (white knockouts
in the Nationals crest set to `var(--paper)`); width and height dropped; the
viewBox tightened to the drawn bounds. No shape was redrawn.
