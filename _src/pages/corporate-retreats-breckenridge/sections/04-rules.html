Caps and curfews, kept as written.

Breckenridge’s reported noise limits vary by zone, residential and commercial, with the town manager able to permit above them, and we couldn’t reach the code text directly when we checked. So the venue’s number is the one that governs, and we ask for it at contract. The figures, with sources and the date checked, are on the mountain corridor page.

A town cap is measured at a property line, so the distance between the band and that line decides how much sound the evening has to work with, which is why the venue name is the first thing we’ll ask for. Tell us the curfew when you book, and the set is built to land on it.
