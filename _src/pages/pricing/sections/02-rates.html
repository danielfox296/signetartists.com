How the number is built

Two parts. A call-out covers the evening we commit regardless of length: travel, load-in, setup, sound check, strike, load-out and production. Then an hourly rate for performance time.

A duo playing one hour still uses a whole evening, so the call-out prices the evening and the hourly rate prices the music. A one-hour cocktail set and a four-hour reception both come out honest.

There is no overtime rate. Additional time bills at the same hourly figure in 30-minute increments. Hour five costs what hour four cost, so the only question at 11pm is whether the crowd wants one more.
